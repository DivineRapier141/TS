Роботизована рука

Розробка багатосервового маніпулятора з використанням RaspberryPi та драйвера PCA9685. Проект включає написання Python скриптів для послідовного керування моторами та налаштування зовнішнього живлення.

2D Гра з керуванням жестами дрона

Інтерактивна гра на Python з використанням Pygame. Управління реалізовано через комп'ютерний зір: камера зчитує рухи рук за допомогою MediaPipe HandLandmarker та OpenCV для контролю ігрових об'єктів.
